# LetsWritePaper website

Introduction and download page for the desktop app. Production: [letswritepaper.vercel.app](https://letswritepaper.vercel.app). The Vercel project is `letswritepaper`, and this directory is the project root.

```sh
pnpm install
pnpm dev
```

Download links use the latest GitHub release of `GITHUB_REPOSITORY` (`owner/name`). See `.env.example`. When it is unset, the site uses `amirrezaalasti/LetsWritePaper`. The installers are `LetsWritePaper-macos.dmg`, `LetsWritePaper-x64-setup.exe`, and `LetsWritePaper-x64.AppImage`.

```sh
pnpm build
```
