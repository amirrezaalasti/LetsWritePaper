# Security policy

## Supported versions

LetsWritePaper is an early 0.1 project. Security fixes go into the latest release on the default branch.

## Reporting a vulnerability

Please report a vulnerability privately. A public issue or pull request can expose people who are running the app or a relay before a fix exists.

Email amirrezaalasti@gmail.com. Once this repository is on GitHub, you can also use **Security → Report a vulnerability**, which opens a private advisory.

Include what you can:

- The version or commit you tested.
- Whether the issue is in the desktop app, the `paper` CLI, the MCP server, or the relay (`paper serve`).
- Steps that show the problem, and the impact you expect.

You will get an acknowledgement within a few days. Please give the project time to fix the issue before writing about it in public.

A share link contains the paper's access token. Treat a leaked link as a secret: anyone who has it can read and edit that paper.
